# Aditya Uniyal — UGC Portfolio

Static portfolio built with HTML, CSS and JavaScript.

## Local preview

From this directory, run:

```sh
python -m http.server 8000 --bind 127.0.0.1
```

Open http://localhost:8000. Press Ctrl+C to stop the server.

## Publishing

GitHub Pages serves the root of the `main` branch. Push changes to `main` to update the website.

Instagram embeds depend on Instagram availability and browser privacy settings; each reel includes a direct link.
